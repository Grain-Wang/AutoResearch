## 本轮方向修正

接受审稿人的核心新颖性意见。TIGER 已覆盖 natural-language task instruction、冻结异构 VFM、token-level dense routing 和 expert-exclusion contribution alignment，因此不再把“语言条件 + 冻结专家 + dense contribution teacher”写为剩余空间。Main 重命名为 **Main-PR**，唯一待否证边界收紧为：两个冻结的同任务 metric-depth candidates 之间，在 clean retention `>=0.80` 约束下最小化局部受控 caption error 的 upper-tail regret。

Claim-M 主判据同步改为：dev 只在 retention `>=0.80` 的 thresholds 中选择最低 CVaR operating point，冻结后在 internal-test 比较 `CVaR` 与 `WorstOf3`；全曲线 hypervolume 降为 secondary sensitivity。
