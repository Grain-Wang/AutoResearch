## 2. 🔄 改进效果评估

当前分支 `chore/integrate-tools-and-paper1` 中没有 `paper1/steps/` 文件，也没有已有的 `paper1/responce_from_reviewer/` 评审文件。因此，本轮无法核对“上一轮关切—修改动作—验证结果”的闭环；以下评价针对两份 Idea 文档中已经体现的方案收敛程度。

- ✅ **有效改进**：
  - 两个方向都明确标为 **Research Opportunity，而非 Paper Candidate**，并写出否证条件、止损阈值和 killer baselines，叙事克制性明显优于直接包装成“新框架”。
  - CoVoL-Depth 将路由目标从抽象“文本可信度”改成相对冻结视觉分支的任务损失差 `v* = loss(D0)-loss(D1)`，并引入单边 regret；该定义至少让路由决策与最终深度误差直接对应。
  - Q-GeoRoute 区分“在全部 token 已计算后做软门控”和“真正减少 VGGT 执行深度/LLM token 成本”，并把主结果设为 accuracy–cost Pareto，而非只展示 attention 图。
  - 两份文档均给出负结果解释，能够阻止“简单基线已覆盖仍继续包装”的常见 CCF-C 拒稿问题。

- ⚠️ **部分解决**：
  - 数据集、指标、基线和消融已经列出，但尚未绑定代码仓库版本、训练划分、caption 生成器、随机种子、硬件、参数预算和统计检验；目前是实验愿望清单，不是可执行协议。
  - CoVoL-Depth 提到 `L_sparse` 与正确文本收益共同阻止全关门，但这不是充分保证。若语言候选本身训练不足、router 与 residual head 联合漂移，`v*` 会成为移动目标，最终仍可退化为几乎恒为零的 gate。
  - CoVoL-Depth 尚未隔离视觉难度、`D0/D1` 候选质量、残差幅度和文本语义四类因素。若只用 `|D1-D0|`、`D0` 置信度或图像难度即可预测优势，论文的“语言价值”解释将退化为普通专家选择。
  - Q-GeoRoute 的 7 子集枚举适合验证层级差异，但离线缓存完整 VGGT 特征并不能证明真实计算节省；tap 子集只减少 projector/LLM token 成本，只有 `Lmax` early exit 才减少 geometry encoder 成本，二者必须分开计账。

- ❌ **无效/偏离**：
  - 缺少 `paper1/steps/` 使修改历史、失败实验和决策依据不可审计；下游 Agent 无法判断哪些问题已处理、哪些只是文字重述。
  - CoVoL-Depth 的近邻审计缺少至少三项关键工作：语言引导深度鲁棒性研究 `arXiv:2404.08540`、Language as Prior, Vision as Calibration `arXiv:2601.01457`、CapDepth `arXiv:2607.28285`。因此，“错误语言危害”“冻结视觉基线+语言校准”“语义原子/细粒度文本筛选”均不能作为新颖性来源。
  - Q-GeoRoute 虽列出 GeoSR `arXiv:2603.26639`，但当前表述仍容易被概括为“query-conditioned geometry routing + token pruning”。真正剩余的可辩护边界只有：**模型相对的最小充分层子集、显式成本约束、可执行 early exit**。
  - `paper1` 同时保留两条机制、任务和实验栈完全不同的主线，尚未形成单一论文问题。对强 CCF-C 而言，这会造成资源分散、Related Work 失焦和实验闭环延迟。

## 3. 🔍 强CCF-C维度深度审查

- **问题与动机**：
  - CoVoL-Depth 是当前更合适的主线。可将问题收缩为：**自动图像 caption 含局部、可机器验证的语义错误时，如何判断语言候选是否应替代冻结的纯视觉深度候选，并在无收益区域严格回退。** 这个定义具体、可自动评测，也符合强 CCF-C 对细分问题清晰度的要求。
  - “语言会损害深度估计”本身已由 2024 年鲁棒性研究系统讨论，不能作为贡献；论文必须贡献“增益是否可预测、哪些信息提供额外预测力、如何把预测转成可验证的选择性风险控制”。
  - 当前四类文本干预混合了自然 caption 缺陷、结构化语义冲突和全局无关文本。主任务必须固定为自动 caption，并分别报告自然错误与合成干预，不能把容易识别的随机 caption 结果外推为真实安全性。
  - Q-GeoRoute 同时包含层选择、token 选择、预算选择、early exit、静态和动态任务，范围超过一篇强 CCF-C 初版所需。若作为备用方向，Phase 0 只验证“同一场景的不同问题是否对应不同最小充分最大层深度”。

- **技术完备性**：
  - CoVoL-Depth 必须采用明确的两阶段协议：先独立训练并冻结 `D0` 与 `D1`，再用缓存预测训练 router。否则 residual head、router 和 value target 可共同适配，`v*` 不再是稳定教师。
  - `D1` 的定义必须固定。若 `D1=D0+Delta`，需要声明 `Delta` 的训练数据、损失、是否看过错误 caption、是否与 `D0` 共享参数，以及 `D0` 与 `D1` 的推理成本。缺少这些信息时，任何 gate 比较都可能不公平。
  - patch loss 要给出唯一实现：patch 尺寸/分层区域、有效深度像素掩码、损失聚合、边界 patch 处理和从 patch gate 上采样到像素的规则。不同实现会显著改变 value label 的噪声。
  - `L_sparse` 不应承担防止全关门的核心职责。更可审计的写法是约束式目标：在 clean caption 上保留至少 `kappa` 比例的语言增益或覆盖率，同时最小化 corrupted-caption regret；`kappa` 必须在验证集预注册。
  - “counterfactual”目前只是受控文本替换，并未建立结构因果模型或可识别的反事实量。正文宜使用 **controlled caption intervention**；`value of language` 应限定为“相对两个冻结候选的经验 advantage”，避免因果 overclaim。
  - Q-GeoRoute 的“最小充分子集”是相对于冻结模型、答案损失和容差 `epsilon` 的模型相对子集，不是任务固有真值。成本函数必须把 VGGT encoder、projector、LLM prefill 和稀疏 packing 的实际耗时分别列出，禁止把理论 FLOPs 等同于 wall-clock 收益。

- **实验可信度**：
  - 当前没有任何结果，因此尚不能支持问题真实性、机制有效性或可复现性。
  - 缺陷复现应使用同图像配对设计：同一图像分别输入 clean caption、自然错误 caption、结构化错误 caption 和 null caption，比较 `D1` 相对同一个 `D0` 的误差差值。统计单位应为图像或场景，而不是把 patch 当作独立样本夸大显著性。
  - caption 干预必须按模板、生成器和错误类型做 train/dev/test 隔离；至少保留一个未见错误类型和一个未见 captioner。若训练与测试共享替换词表或表面模板，router 可能只识别文本伪影。
  - Baseline 公平性要求所有 gate 读取相同缓存的 `D0/D1`、相同训练样本和相同 region granularity；参数量与训练步数需记录。CLIP gate、uncertainty gate、visual-only advantage classifier、`|D1-D0|` gate、标准 learning-to-defer、caption corruption augmentation 都必须进入同一 Pareto 图。
  - 结果应报告三个独立训练种子、图像级 paired bootstrap 95% CI、clean gain retention、平均 regret、worst-of-N、CVaR、gate coverage 和额外延迟。只报告 AbsRel 均值无法证明选择性风险控制。
  - 正式实验前必须先做“语义增量预测力”canary：在匹配 `D0` 难度、候选差异幅度和残差范数后，加入文本—区域语义特征是否仍提高 held-out advantage prediction。该实验失败时，应直接撤回语义机制主张。

- **叙事克制性**：
  - 两份文档当前使用 Research Opportunity、否证条件和负结果解释，这一点符合强 CCF-C 写作习惯。
  - 在实证前，标题中的“安全”只能表示存在显式 fallback，不能表示已获得非退化保证；除非给出有限分布下的风险界或统计覆盖保证，否则正文应改用“selective”或“fallback-aware”。
  - 不应主张“首次发现错误文本影响”“首次进行细粒度 caption 处理”“首次使用 query gate”。可主张的内容必须收缩到经实验支持的具体决策变量和训练协议。
  - Q-GeoRoute 若未实现真实 early exit，只能写成“模型相对层选择分析”，不能写成预算化推理方法。

## 4. ⚔️ 模拟评审攻击 (Top 3 Rejection Risks for Strong C-C)

1. **“这不是论文，只是两份写得很完整的实验计划。”**
   - 攻击依据：没有代码、数据 manifest、checkpoint、主结果、消融、统计区间或失败记录。
   - 现有内容能否扛住：**不能。** 文档完整度不能替代至少一次跨数据集缺陷复现和一次可重复 canary。

2. **“CoVoL-Depth 只是标准 two-expert learning-to-defer；把标签改成 loss difference 不构成方法贡献。”**
   - 攻击依据：`D0/D1 + advantage target + gate` 是通用专家选择范式；单边 regret 和 patch 化也可能只是常规损失设计。
   - 现有内容能否扛住：**不能。** 当前没有 visual-only advantage classifier、residual-magnitude gate、标准 defer baseline，也没有证明文本语义在控制混杂后提供额外预测力。

3. **“实验通过合成错误和移动 oracle 制造了收益；Q-GeoRoute 的成本收益也来自事后稀疏统计。”**
   - 攻击依据：caption 模板泄漏、同一 captioner 训练测试、router 与语言候选共同训练、patch 伪重复、完整 VGGT 已执行后再选择层，都可能产生虚假结论。
   - 现有内容能否扛住：**不能。** 必须冻结候选、隔离生成器/错误族、增加自然错误切片，并用真实 latency 验证 early exit。
